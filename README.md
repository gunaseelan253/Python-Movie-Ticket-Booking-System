# Movie Ticket Booking System

## Project Overview

The Movie Ticket Booking System is a console-based Python application developed to manage basic movie ticket booking operations. The project demonstrates the practical implementation of core Python programming concepts.

## Features

* Display available movies and ticket prices
* Book movie tickets
* Select seats
* Generate unique booking IDs
* View booking details
* Cancel bookings
* Calculate total ticket amount
* Validate user inputs and handle invalid entries

## Technologies Used

* Python
* Functions
* Dictionaries
* Conditional Statements
* Loops
* Exception Handling
* Random Module

## System Functionality
The application provides a menu-driven interface with the following operations:

1. View Movies
2. Book Ticket
3. View Booking
4. Cancel Booking
5. Exit

During booking, the system collects customer details, movie selection, number of tickets, and seat numbers. It then generates a booking ID and calculates the total ticket amount.

## Project Objective

The objective of this project is to develop a simple and functional ticket booking application while applying Python programming concepts to a real-world use case.

## Key Concepts Demonstrated

* Modular programming using functions
* Data management using dictionaries
* Input validation
* Exception handling
* Dynamic price calculation
* Booking management using unique booking IDs
